تنظیمات Supabase

اینجا فقط از Publishable/Anon Key عمومی استفاده کن. هرگز Service Role یا Secret Key را داخل این برنامه قرار نده.

Policy دسترسی Storage
create policy "ImageFrame Studio uploads"
on storage.objects for insert to anon
with check (bucket_id = 'imageframe');

create policy "ImageFrame Studio deletes"
on storage.objects for delete to anon
using (bucket_id = 'imageframe');

-- Make the bucket public for direct ImageFrame URLs.
