# ForwardHub

A responsive Persian-language central link hub for TheROMZ52's known websites and project repositories.

## Contents

- `index.html` — standalone static website; no build step or dependencies required.
- Links to KootletLand, KillZone, and selected project repositories.

## Run locally

Open `index.html` in a browser.

## Hosting

The page is currently stored at `ForwardHub/index.html` in this repository. To publish it as a standalone site, configure GitHub Pages or another static host to use the `ForwardHub` directory as its publishing root.

The website URLs in the page are the known Vercel deployment URLs; update them in `index.html` if deployments or custom domains change.
