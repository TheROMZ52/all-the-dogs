## 02 / نکته‌ها

هر پوشه یک پروژه یا نمونهٔ اولیهٔ مستقل است. برای مشاهدهٔ سورس و راهنمای مخصوص هر پروژه وارد پوشهٔ آن شو.

در ریشهٔ این مخزن چند فایل مربوط به توسعه و عیب‌یابی هم وجود دارد. پیش از اشتراک‌گذاری یا استفادهٔ دوباره از مخزن، آن‌ها را بررسی کن و هیچ رمز، توکن دسترسی، نشانی خصوصی یا اطلاعات شخصی را Commit نکن.
