# Zahra Nails

نسخه اول وب‌سایت فارسی مدیریت نمونه‌کارها و نوبت‌دهی ناخن.

## امکانات
- گالری نمونه‌کارها و مدیریت تصاویر
- مدیریت خدمات، قیمت و مدت زمان
- درخواست نوبت با شماره تماس و کد پیگیری
- تأیید، رد و لغو نوبت‌ها از پنل مدیریت
- PostgreSQL مستقل و اجرای Docker روی VPS

## راه‌اندازی
سورس کامل پروژه باید در همین پوشه استخراج شود. پس از قرارگیری فایل‌های پروژه، فایل `.env.docker.example` را به `.env` کپی کنید، مقادیر محرمانه را تغییر دهید و اجرا کنید:

```bash
docker compose up -d --build
```

برای جزئیات کامل، به `README.md` داخل سورس پروژه مراجعه کنید.

> توجه: این فایل فقط راهنمای پوشه است؛ فایل آرشیو و سورس کامل هنوز در این commit بارگذاری نشده‌اند.
