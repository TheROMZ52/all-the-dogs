# Zahra Nails

وب‌سایت فارسی و راست‌چین برای گالری نمونه‌کارها، خدمات و قیمت‌ها، ثبت درخواست نوبت و پنل مدیریت.

## نسخه به‌روزشده

- دیتابیس SQLite محلی؛ بدون نیاز به نصب PostgreSQL یا مدیریت دیتابیس جداگانه
- ذخیره‌سازی فایل دیتابیس در `data/zahra-nails.sqlite`
- نوبت‌دهی با کد پیگیری و شماره تماس، بدون حساب مشتری
- مدیریت گالری، خدمات، قیمت‌ها و وضعیت نوبت‌ها
- SEO پایه: متادیتای اختصاصی، canonical، robots.txt، sitemap.xml، llms.txt، JSON-LD، BreadcrumbList، favicon و صفحه 404
- Docker تک‌سرویسی و ساده‌سازی راه‌اندازی

## راه‌اندازی

نیازمند Node.js نسخه 20 یا بالاتر:

```bash
cp .env.example .env
```

در `.env`، کلید `SESSION_SECRET`، نام کاربری و رمز قوی مدیر و دامنه واقعی `PUBLIC_BASE_URL` را تنظیم کن؛ سپس:

```bash
npm install
npm start
```

یا برای اجرای Docker، پس از تنظیم فایل `.env`:

```bash
docker compose up -d --build
```

پنل مدیریت: `/admin/login`

## اطلاعات لازم برای SEO محلی

در تنظیمات پنل مدیریت، نام برند، شماره تماس، نشانی و مختصات واقعی را وارد کن. از داده ساختگی برای اطلاعات کسب‌وکار استفاده نمی‌شود. `PUBLIC_BASE_URL` باید به دامنه واقعی سایت اشاره کند.
