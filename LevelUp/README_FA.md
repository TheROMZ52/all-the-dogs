# LEVEL UP 👑 — نسخه ۱.۱

یادآور روزانه با امتیاز، سطح و استریک 🔥

## تازه‌ها در ۱.۱
- سیستم امتیاز: هر کار انجام‌شده ۱۰ امتیاز؛ هر ۱۰۰ امتیاز یک سطح بالاتر + پیام جشن
- استریک روزانه و رتبه‌ها (تازه‌کار ← جنگجو ← قهرمان ← استاد ← افسانه)
- طراحی جدید راست‌به‌چپ با ارقام فارسی، کارت‌های گرد و نوار پیشرفت
- ویرایش یادآور با زدن روی کارت، انتخاب ساعت ساده‌تر
- حذف با امکان «برگردان»
- ریست خودکار تیک‌ها هر روز
- یادآورها بعد از ریبوت و آپدیت برنامه دوباره فعال می‌شوند
- زدن روی اعلان، برنامه را باز می‌کند
- آیکون و آیکون اعلان جدید
- رفع باگ نام روزهای هفته در انتخاب روز تکرار

## ساخت APK
گیت‌هاب اکشنز با هر push روی شاخه `level-up-build` خودش APK می‌سازد.
یا در Android Studio: Build > Build APK(s).

## نکته
اگر اندروید خواست، اجازه‌ی اعلان و «هشدار و یادآور» را فعال کن. در گوشی‌های شیائومی اجرای پس‌زمینه را هم باز بگذار.
