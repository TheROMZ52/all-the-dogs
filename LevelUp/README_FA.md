# LEVEL UP 👑 — پروژه اندروید

این یک پروژه شروعِ قابل بازکردن در Android Studio است؛ APK کامپایل‌شده نیست.

## امکانات نسخه اول
- پروفایل جداگانه «روز مدرسه» و «تعطیلات»
- افزودن یادآور با ساعت و دقیقه دلخواه
- انتخاب روزهای تکرار
- اعلان اندروید و تیک انجام‌شدن کار
- ذخیره محلی فهرست کارها

## ساخت APK
1. Android Studio را روی رایانه نصب کن.
2. از File > Open پوشه LEVEL_UP را باز کن.
3. صبر کن Gradle Sync تمام شود.
4. برای ساخت فایل نصب: Build > Build Bundle(s) / APK(s) > Build APK(s)
5. فایل APK در مسیر app/build/outputs/apk/debug قرار می‌گیرد.

## نکته مهم
- هنگام اولین اجرا، اجازه اعلان‌ها را بده.
- در بعضی گوشی‌های شیائومی باید برای برنامه اجازه اعلان و اجرای پس‌زمینه را از تنظیمات گوشی فعال کنی.
- برای هشدار دقیق‌تر، در صورت درخواست اندروید، اجازه Alarms & reminders را هم فعال کن.
- این نسخه پایه است؛ آمار پیشرفته، تقویم، پشتیبان‌گیری، ویرایش یادآورها و همگام‌سازی هنوز اضافه نشده‌اند.
