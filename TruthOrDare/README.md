# جرئت یا حقیقت

یک بازی مستقل و فارسی برای دورهمی‌ها، ساخته‌شده با HTML، CSS و JavaScript خالص.

## اجرا
فایل `index.html` را در مرورگر باز کنید. نیازی به نصب وابستگی یا فرایند build نیست.

## امکانات
- افزودن و حذف نام بازیکن‌ها
- انتخاب تصادفی پرسشگر و جواب‌دهنده (دو نفر متفاوت)
- انتخاب حقیقت یا جرئت توسط جواب‌دهنده
- بیش از ۱۰۰ سؤال حقیقت و بیش از ۱۰۰ چالش جرئت
- فیلتر سطح و موضوع
- جلوگیری از تکرار سؤال/جرئت تا زمان تمام شدن گزینه‌های همان فیلتر
- تاریخچه دورها
- ذخیره فهرست بازیکن‌ها در حافظه محلی مرورگر

## حریم خصوصی
اطلاعات بازیکن‌ها فقط در `localStorage` همان مرورگر ذخیره می‌شود و هیچ داده‌ای به سرور ارسال نمی‌شود.

## نکته
هر بازیکن می‌تواند هر سؤال یا چالشی را رد کند. بازی برای سرگرمی دوستانه طراحی شده است.
