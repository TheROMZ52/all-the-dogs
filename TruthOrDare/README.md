# جرئت یا حقیقت

نسخه مستقل فارسی بازی جرئت یا حقیقت با HTML، CSS و JavaScript ماژولار.

## اجرا
فایل‌ها را از طریق یک وب‌سرور محلی یا Vercel اجرا کنید. برای PWA و Service Worker استفاده از HTTPS یا localhost لازم است.

## امکانات
- انتخاب تصادفی زوج پرسشگر و جواب‌دهنده با مولد تصادف امن مرورگر
- جلوگیری از تکرار زوج یکسان تا حد امکان
- انتخاب حقیقت یا جرئت توسط جواب‌دهنده
- بانک سؤال و چالش با سطح‌بندی و دسته‌بندی
- جلوگیری از تکرار سؤال تا تمام شدن موارد فیلتر فعلی
- امکان رد کردن هر سؤال یا چالش بدون فشار
- تاریخچه تا ۱۰۰ دور با زمان و وضعیت رد شدن
- ذخیره خودکار وضعیت کامل بازی، حتی در میانه نمایش سؤال
- ذخیره دوگانه: IndexedDB به‌عنوان پایگاه اصلی و localStorage به‌عنوان پشتیبان فوری
- بازیابی خودکار از نسخه سالم‌تر در صورت خرابی یکی از ذخیره‌سازها
- مهاجرت اطلاعات نسخه قبلی بدون حذف نام بازیکن‌ها
- همگام‌سازی تغییرات میان تب‌های باز همان مرورگر
- خروجی گرفتن و بازیابی فایل پشتیبان JSON
- PWA نصب‌پذیر با کش نسخه‌بندی‌شده و پشتیبانی آفلاین
- به‌روزرسانی Service Worker و فایل‌های برنامه بدون گیرکردن روی نسخه قدیمی
- رابط واکنش‌گرا، دسترس‌پذیر و سازگار با موبایل

## ساختار پروژه
- \`index.html\`: ساختار رابط
- \`styles.css\`: طراحی واکنش‌گرا
- \`app.js\`: منطق بازی و کنترل رابط
- \`storage.js\`: ذخیره‌سازی دوگانه، اعتبارسنجی و مهاجرت داده
- \`manifest.webmanifest\`: تنظیمات نصب PWA
- \`sw.js\`: کش آفلاین و مدیریت نسخه
- \`icon.svg\`: آیکون برنامه

## ذخیره‌سازی و حریم خصوصی
داده‌ها فقط در مرورگر و دستگاه کاربر ذخیره می‌شوند و به سرور ارسال نمی‌شوند. ذخیره‌سازی اصلی از IndexedDB و نسخه پشتیبان فوری از localStorage استفاده می‌کند. پاک کردن داده‌های سایت یا تعویض مرورگر/دستگاه ممکن است داده‌های محلی را حذف کند؛ برای انتقال یا نگهداری بلندمدت، از خروجی پشتیبان استفاده کنید.

## پشتیبان‌گیری
از دکمه «خروجی پشتیبان» یک فایل JSON دریافت کنید. برای بازیابی همان فایل یا فایل پشتیبان سازگار را از «بازیابی پشتیبان» انتخاب کنید.
