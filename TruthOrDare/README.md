# جرئت یا حقیقت

یک بازی مستقل و فارسی برای دورهمی‌ها، ساخته‌شده با HTML، CSS و JavaScript خالص.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا نسخه آنلاین را از طریق Vercel اجرا کنید. نیازی به نصب وابستگی یا فرایند build نیست.

## امکانات
- افزودن و حذف نام بازیکن‌ها
- انتخاب تصادفی پرسشگر و جواب‌دهنده (دو نفر متفاوت)
- انتخاب حقیقت یا جرئت توسط جواب‌دهنده
- بانک گسترده سؤال‌ها و چالش‌ها با فیلتر سطح و موضوع
- جلوگیری از تکرار سؤال/جرئت تا زمان تمام شدن گزینه‌های همان فیلتر
- تاریخچه دورها
- ذخیره خودکار فهرست بازیکن‌ها، دور فعلی، افراد انتخاب‌شده، سؤال فعلی، تاریخچه، فیلترها و سؤال‌های استفاده‌شده
- بازیابی وضعیت دقیق بازی پس از رفرش یا باز کردن دوباره سایت در همان مرورگر
- PWA قابل نصب روی دستگاه‌های پشتیبانی‌شده
- پوسته آفلاین؛ پس از اولین بارگذاری موفق، فایل‌های اصلی بازی کش می‌شوند و بازی بدون اینترنت هم باز می‌شود

## ساختار فایل‌ها
- `index.html`: ساختار صفحه
- `styles.css`: استایل‌ها
- `app.js`: منطق بازی و ذخیره‌سازی
- `manifest.webmanifest`: تنظیمات PWA
- `sw.js`: سرویس‌ورکر و کش آفلاین
- `icon.svg`: آیکون برنامه

## ذخیره‌سازی و حریم خصوصی
اطلاعات فقط در `localStorage` همان مرورگر و همان دستگاه ذخیره می‌شود و به سرور ارسال نمی‌شود. پاک کردن داده‌های سایت یا استفاده از مرورگر/دستگاه دیگر، این اطلاعات محلی را حذف یا جدا می‌کند.

## نکته
برای نصب، در مرورگرهای پشتیبانی‌شده از دکمه «نصب برنامه» استفاده کنید. در مرورگرهایی که این دکمه را ارائه نمی‌کنند، از گزینه «افزودن به صفحه اصلی» در منوی مرورگر استفاده کنید. هر بازیکن می‌تواند هر سؤال یا چالشی را رد کند.
